# 管理后台列表操作提效 任务文档

## 背景

管理后台 9 个列表页(约 4120 行)缺少统一交互抽象,各自手写搜索/分页/Modal/空状态,行为互相不一致,且存在统计口径错误、防抖失效、空数据仍渲染分页等真 bug。无批量操作,操作列可访问性差,切换操作无反馈。本次聚焦列表页操作效率提效(P1),不做大范围组件库抽象(留 P0)。

详见 `docs/superpowers/specs/2026-07-12-管理后台列表操作提效-设计.md`。

## 目标

- 修复 3 类真 bug(orders 统计卡片、debounce 失效、空数据分页)
- 统一搜索(防抖 300ms)、分页(跳页+pageSize)行为
- 补操作反馈(toast)、可访问性(aria-label)、批量操作
- 抽取最小共享件:`useDebouncedValue` hook、`<Pagination>`、`<Modal>`、`<EmptyState>`

## 范围

- 批次1:修 bug + 搜索统一 + `<Pagination>` 迁移 8 页
- 批次2:`<Modal>` 迁移 + 操作列 aria/文字 + 切换操作 toast + `<EmptyState>`/skeleton + 表头 sticky
- 批次3:tools 批量操作(前端循环),复制到 reviews/UserManagement

## 非范围

- 不抽 `<DataTable>`/`<FilterBar>`/`<StatusBadge>`/`<Form>`(P0)
- 不做命令面板/侧边栏修复(P2)、语义色 token/暗色模式(P3)
- 不重构表单页、不改 API 契约与后端
- 不新增后端批量接口(批量操作用前端循环)

## 备注

- 批量操作后端无接口,用前端循环单条调用 + 进度 toast;量大时再补后端批量接口
- orders 统计卡片后端无分状态统计,移除三张分状态卡片(保留"全部订单"),正确统计留待后端
- `utils/index.ts` 裸 `debounce` 不改动,用 `useDebouncedValue` hook 替代调用方
- 切换操作用即时切换+toast(可逆),删除保留确认 Modal(不可逆);undo 为可选增强
