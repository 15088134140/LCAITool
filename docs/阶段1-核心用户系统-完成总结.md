## 📦 后端API完成情况

### ✅ 已完成的接口（23个）

**认证模块**（5个）：
- `POST /api/v1/auth/register` - 用户注册
- `POST /api/v1/auth/login` - 用户登录（OAuth2）
- `POST /api/v1/auth/wechat` - 微信登录
- `POST /api/v1/auth/refresh` - 刷新Token
- `POST /api/v1/auth/logout` - 登出

**用户模块**（8个）：
- `GET /api/v1/users/me` - 获取当前用户信息
- `PUT /api/v1/users/me` - 更新当前用户信息
- `POST /api/v1/users/verify-id` - 实名认证提交
- `GET /api/v1/users/balance` - 查询积分余额
- `GET /api/v1/users/transactions` - 积分流水列表
- `POST /api/v1/users/change-password` - 修改密码 ✨
- `POST /api/v1/users/send-code` - 发送手机验证码 ✨
- `POST /api/v1/users/change-phone` - 更换手机号 ✨

**管理员模块**（10个）：
- `GET /api/v1/admin/users` - 用户列表（分页、搜索、筛选）
- `GET /api/v1/admin/users/{id}` - 用户详情
- `PUT /api/v1/admin/users/{id}` - 编辑用户信息
- `PUT /api/v1/admin/users/{id}/status` - 启用/禁用账号
- `POST /api/v1/admin/users/{id}/adjust-balance` - 调整积分
- `PUT /api/v1/admin/users/{id}/roles` - 分配用户角色
- `GET /api/v1/admin/roles` - 角色列表
- `POST /api/v1/admin/roles` - 创建角色
- `PUT /api/v1/admin/roles/{id}` - 编辑角色
- `DELETE /api/v1/admin/roles/{id}` - 删除角色

- ✅ 角色权限控制（RBAC）
- ✅ 密码哈希存储（bcrypt）

- ✅ 统一响应格式 + 全局异常处理

## 🚀 快速启动指南

### 后端启动
```bash
cd apps/backend
pip install -r requirements.txt
alembic upgrade head
python -m app.main
```
访问：http://localhost:8000/docs

### 管理端启动
```bash
cd apps/frontend-admin
npm install
npm run dev
```
访问：http://localhost:3001

### 用户端启动
```bash
cd apps/frontend-user
npm install
npm run dev
```
访问：http://localhost:3000
