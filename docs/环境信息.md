## E2E自动化测试配置

### 数据库说明
⚠️ **所有E2E自动化测试统一使用阿里云PostgreSQL数据库**，不使用SQLite或内存数据库。

### 运行E2E测试前准备

1. **确保数据库表结构已初始化**
   ```bash
   cd apps/backend
   alembic upgrade head
   ```

2. **初始化测试用户**
   ```bash
   python scripts/init_e2e_users.py
   ```

3. **启动后端服务**
   ```bash
   uvicorn app.main:app --reload
   ```

4. **启动前端服务**
   ```bash
   cd apps/frontend-user && npm run dev
   cd apps/frontend-admin && npm run dev
   ```

### 运行E2E测试

```bash
cd apps/backend

# 运行所有E2E测试（有头模式，方便观察）
E2E_HEADLESS=false pytest tests/e2e/ -v -s

# 运行登录测试
E2E_HEADLESS=false pytest tests/e2e/test_e2e_login.py -v

# 运行注册测试
E2E_HEADLESS=false pytest tests/e2e/test_e2e_register.py -v
```
