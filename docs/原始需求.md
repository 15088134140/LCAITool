三、全链路实现storybook-generator的执行器，执行流程如下：
- 第一步：用户界面填写信息：主题、绘画风格（选择 + 可自定义填写）、配音音色（选择）、受众设置、页数设置（页数设置，最小 5、最多30，也可勾选智能决策页数）、是否添加背景音乐、是否添加音效。

- 第二步：生成故事梗概，调用 DeepSeek的，让它根据故事主题，生成故事梗概，系统提示词模版大致如下。

```markdown
根据主题 {{第一步传入的主题}} 写一个短故事。要求：
        1. 用简体中文写作
        2. 不要使用特殊字符、星号或markdown格式
        3. 故事要有趣且富有想象力
        4. 保持在200-300字之间
        5. 分成3-4个自然段落
        6. 使用简单明了的语言
        7. 避免使用括号、方括号或任何可能影响文本转语音的符号`
      : `Write a short story based on the topic "${topic}". Requirements:
        1. Write the story in English using only regular letters and basic punctuation
        2. Do not use any special characters, asterisks, or markdown formatting
        3. Make it interesting and imaginative
        4. Keep it between 200-300 words
        5. Divide it into 3-4 natural paragraphs
        6. Use simple and clear language
        7. Avoid using parentheses, brackets, or any symbols that might interfere with text-to-speech
```

- 第三步：生成绘画提示词

```markdown
你是一个专业的儿童绘本插画师和AI绘画提示词专家，精通中英文双语。
请为这段文字 {{ 第二步产生的故事梗概原文 }} 生成{{ 第一步产生的页数设置 }}的不同场景的绘图提示词。

重要提示：
1. 绘画风格统一使用：{{ 第一步传入的绘画风格 }}，全程严格保持风格、色彩、光影一致
2. 不要在提示词中使用角色名字，而是用具体的外观特征来描述角色。
   例如：不要用"小白兔"，而是描述"一只白色的小兔子，有着蓬松的毛发和红色的眼睛"。
3. 生成的提示词中，text_snippet 必须是与画面相符的中文文本片段。

统一创作硬性要求
### 角色形象和风格的严格一致性
用具体的视觉特征描述角色，而不是用名字。
主角的外观特征（服装、毛色、体型等）在所有场景中必须保持一致。
主角的性格特征要通过外观和动作来体现。
配角的设计风格要与主角协调统一。

### 场景连续性
场景之间要有清晰的故事发展脉络。
环境元素的设计要前后呼应。

### 艺术风格统一
全程严格沿用 {{ 第一步传入的绘画风格 }}，色彩方案、光影效果全程统一。

### 适合儿童绘本的表现方式
画面要富有童趣和想象力。
构图要简单清晰。
情感表达要生动直观。

每个场景必须包含：
1. 场景描述（中文，简短精炼）。
2. 详细中文提示词，总长度≤800字，分段描述：
Character: 角色具体外观、表情、动作（无名字）
Scene: 场景环境、氛围、天气
Lighting: 光线、时间、色调
Composition: 构图、视角、重点
Style: {{ 第一步传入的绘画风格 }}
Additional: 其他重要细节
3. 对应的中文文本片段。

严格按照以下JSON格式输出，只输出JSON，不要额外内容：
[
{
"description": "场景描述",
"prompt": "Character:\n[角色具体特征描述]\n\nScene:\n[场景描述]\n\nLighting:\n[光影描述]\n\nComposition:\n[构图描述]\n\nStyle:\n{{ 第一步传入的绘画风格 }}\n\nAdditional:\n[补充细节]",
"text_snippet": "对应的文本片段",
"importance": "场景重要性评分（1-5）"
}
]
```
