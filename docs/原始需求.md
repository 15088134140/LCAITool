### 3.4 成果管理系统

#### 3.4.1 我的成果列表
- 视图切换：卡片视图 / 列表视图
- 筛选功能：按工具分类（全部 + 系统的工具分类）、按时间范围、按状态
- 搜索功能：按成果名称搜索
- 每个成果卡片：
  - 成果封面缩略图：如果作品中有图，应该以第一个为预览图，没图则显示默认图。
  - 成果名称
  - 使用的工具：点击可以直接跳转到该工具
  - 生成时间
  - 费用
  - 操作按钮：查看、下载、继续优化（只有聊天类工具才支持）、删除

需要明确：状态的操作链路是怎样的？

#### 3.4.2 成果详情页
- 成果封面缩略图：如果作品中有图，应该以第一个为预览图，没图则显示默认图。
- 成果名称
- 成果完整预览
- 所有产出文件列表，可单独下载或打包下载
- 版本历史：如果有迭代创作，显示所有历史版本，可对比查看
- 操作区：
  - 「基于此版本继续优化」
  - 「用同样参数重新生成」
  - 「分享成果」（生成分享链接）
  -  评价
