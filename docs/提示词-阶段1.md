# 阶段一执行方案
## 执行总则
1. 采用**主Agent统筹调度 + 专业子Agent分工落地**模式，主端仅派发任务、汇总进度、验收成果，**不编写任何业务代码**。
2. 自动加载`.claude/memory/project_subsystems.md`项目记忆，全力完成**阶段1核心用户系统**全功能：后端API、管理端前端、用户端前端。
3. 全程自主选定最优技术方案，无需向用户请示、询问、确认需求。
4. 所有产出必须可编译、可运行、可自测，完成接口、功能、联调全维度测试。

## 子Agent分工任务
### 1. 后端API子代理
搭建用户系统后端架构，完成数据表设计、实体分层、用户注册/登录/鉴权/权限管理/信息维护全套接口；统一响应格式、全局异常、参数校验；完成服务启动、接口自测、单元测试，交付可用后端服务与接口文档。

### 2. 管理端前端子代理
搭建后台管理项目，完成用户管理、账号配置、角色权限、账号启停等后台页面开发；封装请求与路由权限，全量对接后端接口，完成页面调试、编译打包测试，交付完整可运行管理端。

### 3. 用户端前端子代理
开发用户登录注册、个人中心、资料编辑等C端页面；实现登录态管理、路由拦截、前端业务逻辑；对接用户侧所有接口，完成流程自测与打包验证。

### 4. 全流程测试子代理
整理全量测试用例，执行接口复测、前后端联调、业务流程全链路测试；排查字段不一致、权限异常、登录失效等问题，推动问题修复，出具阶段整体验收测试报告。

## 执行流程
1. 加载项目记忆，划定阶段1功能范围，并行派发全部开发任务。
2. 收集各子代理开发进度、代码成果、问题卡点，统一协调联调规范。
3. 开发完成后统一进入全量测试环节，问题闭环修复复测。
4. 测试全部通过，汇总完整项目成果、部署说明，完成阶段一全部功能落地。

## 强制规范
1. 严格遵循项目既定架构与代码规范，不随意改动技术标准。
2. 未完成自测的模块不予验收，必须保证功能完整可用。
3. 全程静默自主执行，无多余交互，按期完成全部既定功能。
