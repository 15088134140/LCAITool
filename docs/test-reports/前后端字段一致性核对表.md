## 二、问题汇总与严重程度

### 🔴 严重问题 (必须修复)

1. **注册接口字段完全不匹配**
   - 前端: phone + password + nickname + code
   - 后端: username + password + email
   - 影响: 用户无法注册

2. **User对象字段多处不一致**
   - avatar_url vs avatar
   - is_active (boolean) vs status (int)
   - is_verified vs id_card_verified
   - points vs balance
   - created_at 类型不一致
   - 影响: 用户信息无法正确显示

3. **多个接口路径不匹配**
   - 发送验证码: /auth/send-code vs /users/send-code
   - 实名认证: /users/verify vs /users/verify-id
   - 积分余额: /users/points/balance vs /users/balance
   - 积分流水: /users/points/history vs /users/transactions
   - 影响: 接口调用全部失败

4. **管理端登录响应结构完全不同**
   - 前端期望: user + token
   - 后端返回: access_token + refresh_token + token_type
   - 影响: 管理端无法登录

### 🟡 中等问题 (建议修复)

5. **HTTP方法不一致**
   - 更新用户: 前端用 PATCH，后端用 PUT
   - 影响: 可能导致更新失败

6. **字段命名风格不一致**
   - 管理端: idCardVerified (驼峰)
   - 后端: id_card_verified (下划线)
   - 影响: 字段数据无法正确映射

### 🟢 轻微问题 (可选优化)

7. **前端缺少部分类型定义**
   - 积分流水响应类型
   - 通用分页响应类型
   - 影响: TypeScript 类型检查不完整
