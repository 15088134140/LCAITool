## 修复日期
2026-05-19

## 修复范围

### 一、用户端前端 (frontend-user)

#### 1. API 调用路径修复 (`src/lib/api.ts`)

| 接口 | 修复前 | 修复后 |
|------|--------|--------|
| 发送验证码 | POST /auth/send-code | POST /users/send-code |
| 更新用户 | PATCH /users/me | PUT /users/me |
| 更换手机号 | new_phone 字段 | phone 字段 |
| 实名认证 | POST /users/verify | POST /users/verify-id |
| 实名认证 | id_card 字段 | id_card_number 字段 |
| 积分余额 | GET /users/points/balance | GET /users/balance |
| 积分流水 | GET /users/points/history | GET /users/transactions |

#### 2. User 类型字段修复 (`src/store/useAuthStore.ts`)

**修复前:**
```typescript
interface User {
  id: string;
  username: string;           // 移除
  phone: string | null;
  email: string | null;
  nickname: string | null;
  avatar_url: string | null;  // → avatar
  is_active: boolean;         // → status (number)
  is_admin: boolean;          // 移除
  is_verified: boolean;       // → id_card_verified
  id_card?: string;           // 移除
  points: number;             // → balance
  created_at: string;         // → number (时间戳)
}
```

**修复后:**
```typescript
interface User {
  id: string;
  phone: string | null;
  email: string | null;
  nickname: string | null;
  avatar: string | null;
  id_card_verified: boolean;
  balance: number;
  status: number; // 0=禁用, 1=启用
  created_at: number;
  updated_at: number;
}
```

### 二、管理端前端 (frontend-admin)

#### 1. 登录响应修复 (`src/api/auth.ts`)

**修复前:**
```typescript
interface LoginResponse {
  user: {
    id: string;
    username: string;
    nickname: string;
    avatar?: string;
    role: string;
    permissions: string[];
  };
  token: string;
}
```

**修复后:**
```typescript
interface LoginResponse {
  access_token: string;
  refresh_token: string;
  token_type: string;
}

interface AuthUser {
  id: string;
  phone: string | null;
  email: string | null;
  nickname: string | null;
  avatar: string | null;
  id_card_verified: boolean;
  balance: number;
  status: number;
  created_at: number;
  updated_at: number;
}
```

#### 2. 用户管理类型修复 (`src/api/user.ts`)

**修复字段映射:**
- `idCardVerified` → `id_card_verified`
- `points` → `balance`
- `status: 'active'|'disabled'` → `status: number` (0/1)
- `createdAt: string` → `created_at: number`
- `pageSize` → `page_size`
- `list` → `items`
- `keyword` → `search`

**新增类型:**
- `AdjustBalanceParams` 替代 `AdjustPointsParams`

## 四、遗留问题与注意事项

### ⚠️ 需要后续处理的问题

1. **前端组件中字段引用更新**
   - 组件中引用 `user.avatar_url` 需要改为 `user.avatar`
   - 组件中引用 `user.points` 需要改为 `user.balance`
   - 组件中引用 `user.is_verified` 需要改为 `user.id_card_verified`
   - 组件中引用 `user.is_active` 需要改为 `user.status === 1`

2. **管理端状态显示适配**
   - 后端返回 `status: 0|1`，前端显示时需要映射为 "禁用" / "启用"

3. **时间戳格式化**
   - 后端返回 `created_at: number` (时间戳)，前端需要格式化显示

4. **注册接口验证码逻辑**
   - 前后端都定义了 `code` 字段，但需要确认后端是否实现了验证码校验逻辑

### ✅ 已完全修复的问题

1. ✅ 所有API调用路径一致
2. ✅ User对象核心字段名一致
3. ✅ 请求参数字段名一致
4. ✅ 登录响应结构一致
5. ✅ 分页响应字段名一致
6. ✅ 字段命名风格统一（后端下划线风格）
