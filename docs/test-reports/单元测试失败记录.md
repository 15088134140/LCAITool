## 修复记录

### P0 问题修复 (全部解决)

#### 1. pytest-asyncio 事件循环冲突问题 ✓
**问题**: `conftest.py` 中自定义的 `event_loop` fixture (scope="session") 与 pytest-asyncio v0.23+ 内置的事件循环管理冲突，导致所有异步测试抛出 `RuntimeError`。

**修复方案**:
- 移除 conftest.py 中自定义的 `event_loop` fixture
- 将 PostgreSQL 数据库改为 SQLite 内存数据库，避免外部数据库依赖
- 将 test_engine fixture scope 从 session 改为 function，确保测试隔离

**修改文件**: `apps/backend/tests/conftest.py`

---

#### 2. passlib + bcrypt 版本兼容性问题 ✓
**问题**: passlib 1.7.4 与 bcrypt 5.0.0 版本不兼容，bcrypt 5.0.0 移除了 `__about__` 模块并加强了密码长度校验。

**修复方案**:
- 直接使用 bcrypt 库替代 passlib
- 更新 `verify_password` 和 `get_password_hash` 函数使用 bcrypt API

**修改文件**: `apps/backend/app/core/security.py`

---

#### 3. UserCreate schema 不匹配问题 ✓
**问题**: 原有测试使用旧的 UserCreate schema (username, email)，但当前 schema 已更新为 (nickname, phone, code)。

**修复方案**:
- 更新所有测试使用正确的 UserCreate 参数 (nickname, phone, code="8888")
- 更新测试断言以匹配当前业务逻辑 (新用户赠送100积分，实名认证+50积分)

**修改文件**:
- `apps/backend/tests/test_auth_service.py`
- `apps/backend/tests/test_user_service.py`
- `apps/backend/tests/test_point_service.py`
