# 创作成果管理 — 需求调整设计方案

| 版本 | 日期 | 状态 |
|------|------|------|
| V1.0 | 2026-05-27 | 设计稿（待审批） |

---

## 1. 背景与目标

### 1.1 背景

当前成果管理模块（创作成果列表 `/works` + 成果详情 `/works/detail/[id]`）已实现 P0 功能，但存在以下问题：

- **筛选方式**：使用硬编码工具类型（storybook/ecommerce/marketing/other），未接入系统工具分类体系
- **状态冗余**：`draft / published / archived` 三个状态，`archived` 语义模糊
- **卡片操作**：整个卡片仅做链接跳转，缺少行级操作按钮（下载/继续优化/删除）
- **继续优化**：全部工具都显示"继续优化"按钮，未区分聊天类工具与纯表单工具
- **分页方式**：使用"加载更多"按钮，而非页码分页
- **状态链路**：状态的操作链路未明确

### 1.2 调整目标

1. 筛选改为**系统工具分类**（`ToolCategory`）驱动
2. 精简状态为 `published` / `draft`，去掉 `archived`
3. 卡片上增加行级操作按钮：下载、继续优化（条件展示）、删除
4. "使用的工具"可点击跳转工具详情页
5. 删除改为**软删除 + 确认弹窗**
6. 页码分页替代"加载更多"
7. 详情页增加生成参数展示、"前往工具页重新生成"入口

## 2. 状态模型调整

### 2.1 状态精简

| 状态 | 含义 | 展示行为 |
|------|------|---------|
| `published` | 已发布，正常展示 | 正常展示，分享链接可用 |
| `draft` | 草稿，临时不公开 | 列表展示（半透明降级 + "草稿"标签），分享链接失效，评价正常展示 |

### 2.2 状态变更链路

```
任务完成 → 自动设为 published
用户操作：published ↔ draft（自由切换）
删除 → 确认弹窗 → 软删除（标记 is_deleted=true，列表不可见，数据保留）
```

### 2.3 Draft 状态的影响范围

| 维度 | draft 行为 |
|------|-----------|
| 列表页 | 展示，半透明降级，标注"草稿" |
| 详情页 | 正常访问 |
| 分享链接 | 失效，提示"该成果暂未发布" |
| 文件下载 | 不受影响 |
| 评价展示 | 不受影响 |
| 继续优化/重新生成 | 不受影响 |

## 3. 设计系统

基于 ui-ux-pro-max 的 Minimalism & Swiss Style 风格，对齐项目现有品牌：

| 维度 | 设定 |
|------|------|
| **风格** | Minimalism & Swiss Style — 干净、专业、内容优先 |
| **字体** | DM Sans（现有体系） |
| **主色** | `#1E3A5F` 深蓝（品牌色） |
| **强调色** | `#059669` → `#10B981` 绿色渐变（主按钮/成功） |
| **背景** | `#F8FAFC` |
| **边框** | `#E4E7EB` |
| **效果** | 微悬停 200-250ms、平滑过渡、清晰层级 |
| **设计稿** | `docs/design/works.html` + `docs/design/works-detail.html` |

### 4.2 筛选栏

**工具分类筛选（来自 ToolCategory）**：
- 默认加载所有启用的工具分类
- 第一个为"全部"，后续为各分类名称
- 选中高亮（品牌色渐变背景）
- 点击切换时，前端发请求带上 `category_id` 参数

**状态筛选**：
- 全部状态 / 已发布 / 草稿

**日期范围**：
- 点击弹出日期选择器
- 默认显示当前月份范围

**搜索**：
- 按成果名称搜索
- 实时输入，300ms debounce

### 4.3 卡片设计

每个卡片包含：

| 区域 | 内容 |
|------|------|
| **封面区** | 16:10 比例，第一张图片为封面；无图显示渐变占位 |
| **左上标签** | 工具类型标签（颜色按工具类型区分） |
| **右上标签** | 状态标签（已发布=绿色，草稿=红色+边框） |
| **左下角** | 版本号（`v2`） |
| **右下角** | 文件数 |
| **标题** | 成果名称，1行截断 |
| **时间+费用** | 相对时间 + 消耗积分 |
| **操作按钮** | 下载（主按钮）、继续优化（条件展示）、删除（危险） |

**继续优化按钮显示规则**：
- 仅当工具 `usage_modes` 包含 `dialog` 时展示
- 纯 `form` 工具不展示该按钮

**草稿卡片**：
- `opacity: 0.75` 降级显示
- hover 时恢复 `opacity: 1`

### 4.4 操作按钮交互

| 操作 | 行为 |
|------|------|
| **点击卡片** | 跳转详情页 `/works/detail/[id]` |
| **点击工具标签** | 跳转工具详情页 `/tools/[slug或id]`（阻止卡片跳转） |
| **下载** | 调用 `GET /works/{id}/download`，下载ZIP包 |
| **继续优化** | 跳转工具页，携带 workId 参数 |
| **删除** | 弹确认弹窗 → 确认 → 软删除 → toast 成功 → 卡片移除 |

### 4.5 删除确认弹窗

```
┌──────────────────────────┐
│  确认删除                 │
│                          │
│  确定要删除作品「XXX」吗？  │
│  删除后不可恢复，相关文件   │
│  也会一并清除。            │
│                          │
│        [取消]  [确认删除]   │
│          (白)   (红色)     │

```

- ESC 键可关闭
- 点击遮罩层可关闭

### 4.6 分页

- 页码分页，每页 12 条
- 显示当前页、总页数
- 上一页/下一页按钮

### 4.7 空状态

- 无作品时显示空状态插画 + "还没有创作成果" + "浏览工具"按钮

### 4.8 统计条

位于筛选栏下方、卡片网格上方，展示：
- 总作品数
- 已发布数（排除 draft）
- 总浏览
- 平均版本

## 6. 后端变更

### 6.1 API 变更

**`GET /works` 列表接口**：
| 参数 | 类型 | 说明 |
|------|------|------|
| `category_id` | UUID (可选) | 按工具分类筛选 |
| `status` | string (可选) | `published` / `draft` |
| `search` | string (可选) | 按名称搜索 |
| `date_from` | timestamp (可选) | 时间范围起始 |
| `date_to` | timestamp (可选) | 时间范围结束 |
| `page` | int | 页码 |
| `page_size` | int | 每页数量 |

**新增/变更接口**：
| 方法 | 路径 | 说明 |
|------|------|------|
| `PUT` | `/works/{id}/status` | 切换 published/draft 状态 |
| `GET` | `/tool-categories` | 获取工具分类列表（已有） |

### 6.2 软删除变更

Work 模型新增字段：
```python
is_deleted = Column(Boolean, default=False, comment="软删除标记")
deleted_at = Column(Integer, nullable=True, comment="删除时间戳")
```

`list_user_works` 查询自动过滤 `is_deleted=False`。

### 6.3 Category 筛选逻辑

```
GET /works?category_id={id}
  → JOIN works.tool_id → tools.category_id
  → 筛选 tools.category_id = {id} 的成果
```
