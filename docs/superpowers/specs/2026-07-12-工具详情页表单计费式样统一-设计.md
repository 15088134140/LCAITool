## 1. 背景与目标

### 1.1 背景

用户端工具详情页目前存在**两套**表单与计费布局：

- **专属页（标杆）**：`storybook-generator`、`ecommerce-detail`、`marketing-copywriter` 三个工具有专属 `page.tsx`，其表单组件（`StorybookForm` / `EcommerceForm` / `MarketingForm`）布局完全一致，均采用 `grid lg:grid-cols-3` 三栏布局（左 2/3 表单白色卡片 + 右 1/3 sticky 价格预估面板），与设计稿 `docs/design/tool-detail.html` 的「开始创作」区段一致。三者互为模板，`storybook-generator` 为首选标杆。
- **通用页（异类）**：`creative-video-generator` 没有专属页，访问 `/tools/creative-video-generator` 命中 `[id]/page.tsx` 通用动态路由，渲染共享组件 `ToolCreationForm`。其 `DynamicToolPage` 分支采用 `max-w-2xl mx-auto` **单栏居中**布局，并把 `PriceEstimatePanel` 作为 `DynamicToolForm` 的 `rightSlot` 塞入表单 `<form>` 内部底部，与提交按钮挤在同一行（`flex justify-between`）。

因此 `creative-video-generator` 呈现出与 `storybook-generator` 不一致的式样，违背「参照标杆、不自成一套」的要求。

### 1.2 目标

- 统一通用工具详情页（`[id]` 路由）的表单与计费式样，对齐 `storybook-generator` 标杆与设计稿 `tool-detail.html`。
- 让 `creative-video-generator` 及未来所有走通用路由、未做专属页的工具自动获得标杆式样。
- 不改动三个专属页（已符合标杆），不引入新的共享抽象（遵循 `coding-standards.md`「简单优先」「不引入未被要求的抽象」）。

### 2.3 通用页异类布局结构（ToolCreationForm.DynamicToolPage）

来源：`ToolCreationForm.tsx:69-101`。

```tsx
<section id="start-creation" className="py-20 bg-[#F8FAFC]">
  <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">
    <div className="text-center mb-12">
      <h2 className="text-3xl md:text-4xl font-bold text-brand-dark mb-4">开始创作</h2>
      {/* 无副标题 */}
    </div>
    <div className="max-w-2xl mx-auto">               {/* 单栏居中 */}
      <DynamicToolForm
        ...
        rightSlot={                                    {/* 价格面板塞进表单内部 */}
          <PriceEstimatePanel estimate={estimate} className="mt-6" />
        }
      />
    </div>
  </div>
  <ProgressModal ... />
</section>
```

`DynamicToolForm` 在 `<form>` 底部以 `<div className="flex items-center justify-between gap-4 pt-4">{rightSlot}<button>...</button></div>` 渲染 `rightSlot`，导致价格面板与提交按钮挤在同一行。

### 2.4 差异点对比

| 维度 | 标杆（storybook） | 通用页（DynamicToolPage） |
|------|------------------|--------------------------|
| 整体布局 | `grid lg:grid-cols-3 gap-8` 三栏 | `max-w-2xl mx-auto` 单栏居中 |
| 表单外壳 | `bg-white rounded-2xl p-8 border shadow-sm` 独立白色卡片 | 无白色卡片外壳 |
| 价格面板位置 | 独立右栏 `sticky top-24` | `DynamicToolForm.rightSlot`，嵌在表单内部底部 |
| 价格面板与按钮关系 | 分属不同栏，互不影响 | 挤在同一行 `flex justify-between` |
| 预计耗时卡片 | 有（右栏下方） | 无 |
| section header 副标题 | 有 | 无 |

## 3. 设计方案

### 3.1 改造范围

**仅修改** `apps/frontend-user/src/components/tool-detail/ToolCreationForm.tsx`：

1. `DynamicToolPage`：布局由单栏改为三栏，对齐标杆。
2. `ToolCreationFormWithTabs` 的表单分支：因其调用 `DynamicToolPage`，自动随之对齐（无需单独改）。
3. 补齐 section header 副标题（通用文案）。
4. 补齐右栏「预计耗时」卡片。
5. `DynamicToolPage` 不再通过 `rightSlot` 传 `PriceEstimatePanel`（`rightSlot` 留空 / 不传）。

### 3.2 目标布局结构（DynamicToolPage 改造后，与标杆一致）

```tsx

      <h2 className="text-3xl md:text-4xl font-bold text-brand-dark mb-4">开始创作</h2>
```

### 3.3 文案约定

- **section header 副标题**（通用文案）：`选择适合您的创作方式，简单几步即可生成专属作品`
  - 理由：标杆 storybook 文案为绘本专属（"专属绘本"），通用页需工具无关文案。
- **预计耗时**：`预计耗时：2-5 分钟`
  - 与标杆完全一致。当前为硬编码（标杆亦硬编码）；若后续需按工具区分，可从 `tool` 字段读取，本次不做。

### 3.4 不改动的部分

- `storybook-generator` / `ecommerce-detail` / `marketing-copywriter` 三个专属页及其表单组件。
- 共享组件：`DynamicToolForm`、`PriceEstimatePanel`、`useToolCostEstimate`、`useToolGeneration`、`ProgressModal`、`DialogMode`。
  - `DynamicToolForm` 的 `rightSlot` 机制保留（其他调用方可能在用），仅通用页不再传入。
- `ToolCreationForm` 的 `DialogMode` 分支（`usage_modes=['dialog']`）与「开发中」降级分支。
- 后端、API 契约、seed 数据。
- 不新增共享布局组件（不引入未被要求的抽象）。

## 4. 影响范围与风险

### 4.1 影响文件

- `apps/frontend-user/src/components/tool-detail/ToolCreationForm.tsx`（唯一改动文件）

### 4.2 行为影响

- 仅视觉布局变化，**不改变**任务创建（`useToolGeneration`）、价格计算（`useToolCostEstimate`）、文件上传、校验、登录态等任何逻辑。
- 受益工具：`usage_modes` 为 `['form']` 或 `['form','dialog']` 且走通用路由的工具（含 `creative-video-generator`）。

### 4.3 风险

- **低**。改动局限于一个组件的 JSX 布局，不动状态与提交逻辑。
- 已知遗留（不在本任务范围）：`ToolCreationFormWithTabs` 表单分支调用 `DynamicToolPage` 时，会嵌套产生重复 `<section id="start-creation">` 与「开始创作」标题（外层 WithTabs 已有）。此为现状既有问题，本任务不扩大范围处理，仅在 review 阶段评估是否顺带修正。
