## 1. 项目架构概览

### 1.1 技术栈确认

| 层级 | 技术选型 | 版本 | 说明 |
|------|---------|------|------|
| Monorepo | Turborepo | latest | 多包管理 |
| 用户端前端 | Next.js | 14.x | App Router + SSR |
| 管理端前端 | React + Vite | 18.x / 5.x | 纯SPA |
| UI框架 | Tailwind CSS + shadcn/ui | 3.x | 原子化CSS |
| 后端框架 | FastAPI | 0.100+ | 异步Python框架 |
| 数据库 | PostgreSQL | 16.x | 关系型数据库 |
| ORM | SQLAlchemy + Alembic | 2.x | 数据模型 + 迁移 |
| 缓存/队列 | Redis | 7.x | 缓存 + Celery |
| 状态管理 | Zustand | 4.x | 轻量级状态管理 |
| AI提供商 | 火山方舟(豆包) + Dify | - | 工作流编排 + 模型 |
| 类型系统 | TypeScript + Pydantic | - | 全链路类型安全 |

## 2. 后端设计规范

### 2.1 目录结构

```
apps/backend/
├── app/
│   ├── api/
│   │   ├── v1/

│   │   │   │   ├── users.py     # 用户接口
│   │   │   │   └── health.py    # 健康检查
│   │   │   └── api.py           # 路由聚合
│   │   └── deps.py              # 依赖注入
│   ├── core/
│   │   ├── config.py            # 配置管理 (pydantic-settings)
│   │   ├── security.py          # JWT、密码哈希

│   ├── models/
│   │   ├── base.py              # 基础模型类
│   │   └── user.py              # 用户模型
│   ├── schemas/
│   │   ├── user.py              # Pydantic schema
│   │   └── token.py             # Token schema
│   ├── services/
│   │   ├── user_service.py      # 用户业务逻辑
│   │   └── auth_service.py      # 认证业务逻辑
│   ├── providers/               # 第三方集成（预留）
│   └── main.py                  # FastAPI 入口
├── alembic/                     # 数据库迁移
├── tests/                       # 测试目录
├── requirements.txt
├── .env.example
└── Dockerfile
```

### 2.2 第一阶段后端交付清单

- [x] FastAPI 服务启动框架
- [x] PostgreSQL 连接 (SQLAlchemy 2.0 + asyncpg)
- [x] Redis 连接 (redis-py async)
- [x] JWT 认证系统 (access token + refresh token)
- [x] 用户模型 + 基本 CRUD
- [x] 健康检查接口
- [x] Alembic 迁移配置
- [x] 统一的响应格式和异常处理

### 2.3 核心设计原则

1. **分层架构**：路由层 → 服务层 → 数据层，职责清晰
2. **依赖注入**：所有外部依赖通过 `deps.py` 统一管理
3. **类型安全**：Pydantic 严格校验所有输入输出
4. **异步优先**：所有 IO 操作使用 async/await

## 4. 开发环境与工具链

### 4.1 Docker Compose 本地环境

```yaml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: lcaitool
      POSTGRES_USER: lcaitool
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data

volumes:
  postgres_data:
  redis_data:
```

### 4.2 常用命令

```bash
# 启动基础设施
docker compose up -d

# 启动所有应用
turbo dev

# 单独启动某个 app
turbo dev --filter=frontend-user
turbo dev --filter=backend

# 构建所有应用
turbo build

# 代码检查
turbo lint

# 格式化
turbo format
```

## 6. 关键设计决策记录

| 决策项 | 选择 | 理由 |
|--------|------|------|
| Monorepo 方案 | Turborepo | 现代多包项目标准，开发体验好 |
| 类型系统 | 全量 TypeScript | 生产级项目必备，减少运行时错误 |
| AI 提供商 | 火山方舟 + Dify | 国内访问速度 + 工作流编排能力 |
| UI 组件方案 | shadcn/ui + Tailwind | 高度可定制，与设计系统契合 |
| 初始化策略 | 从零开始脚手架 | 完全匹配技术方案，无多余依赖 |
